# StyleShot：data1200 生成图片

共 **60 张参考图 × 20 条提示词 = 1200 张 PNG**，每张使用 `seed=0`，尺寸为 `512×512`。

图片位于 `images/<参考图编号>/p01.png` 至 `p20.png`。参考图编号为 `C01–C30`、`E01–E30`，目录和文件名与本地生成结果一致。

本次上传包含 2026-11-07 更新参考图后重新生成的 **E21、E30 各 20 张结果**。全部图片保留原始文件字节及 PNG 内嵌的生成参数。

`image_manifest.json` 记录每张图片的编号、提示词编号、大小和 SHA256；`SHA256SUMS` 可用于下载后的完整性校验。完整任务覆盖 60×20，每个编号对应 20 张图片。
